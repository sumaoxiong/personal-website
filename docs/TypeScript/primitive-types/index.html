Primitive Types（基本資料型別）

為什麼要學這個？​

在 TypeScript 中，所有型別的基礎都是 Primitive Types（基本資料型別）。

無論是：

  • 變數宣告
  • 函式參數
  • API 回傳資料
  • Interface
  • React Props

都會使用到這些型別。

理解 Primitive Types 是學習 TypeScript 最重要的第一步。

什麼是 Primitive Type？

Primitive Type（基本資料型別）指的是：

不可再拆分的最基本資料型別

TypeScript 與 JavaScript 共有以下 Primitive Types：

Type說明
string字串
number數字
boolean布林值
null空值
undefined未定義
bigint大整數
symbol唯一識別值

String

用來表示文字資料。

let username: string = "Tom";
let city: string = "Taipei";

字串拼接​

let firstName: string = "Tom";
let lastName: string = "Lee";

let fullName: string = firstName + " " + lastName;

console.log(fullName);

Template Literal（模板字串）​

推薦使用模板字串：

let name: string = "Tom";

let message: string = `Hello ${name}`;

輸出：

Hello Tom

Number

TypeScript 不區分：

  • 整數（Integer）
  • 浮點數（Float）

全部都屬於：

number;

範例​

let age: number = 18;

let price: number = 99.99;

let score: number = 100;

常見運算​

let a: number = 10;
let b: number = 5;

console.log(a + b);
console.log(a - b);
console.log(a * b);
console.log(a / b);

Boolean

表示兩種狀態：

true
false

範例​

let isLogin: boolean = true;

let isAdmin: boolean = false;

搭配條件判斷​

let isLogin: boolean = true;

if (isLogin) {
  console.log("登入成功");
}

Undefined

代表：

已宣告，但尚未賦值

範例​

let username: undefined = undefined;

實際開發較少直接這樣使用。

更常見的是：

let username: string | undefined;

表示：

可能有值
可能沒有值

JavaScript 範例​

let name;

console.log(name);

輸出：

undefined

Null

代表：

開發者主動設定的空值

範例​

let selectedUser: null = null;

常見情境​

let currentUser: string | null = null;

登入後：

currentUser = "Tom";

登出後：

currentUser = null;

Null vs Undefined

這是面試常考題。

項目nullundefined
是否有值沒有沒有
誰設定的開發者JavaScript
使用情境主動清空資料尚未賦值

undefined​

let username;

結果：

undefined

null​

let username = null;

表示：

目前沒有資料

是開發者主動指定的。

BigInt

用於處理超大整數。

Number 最大安全值​

console.log(Number.MAX_SAFE_INTEGER);

輸出：

9007199254740991

超過此範圍可能產生精度誤差。

BigInt​

let bigNumber: bigint = 90071992547409999999n;

注意：

n;

不可省略。

錯誤示範​

let a: bigint = 100n;
let b: number = 10;

console.log(a + b);

錯誤：

Cannot mix BigInt and other types

必須先轉換型別。

Symbol

用於建立唯一值（Unique Value）。

即使內容相同：

Symbol("id");

每次建立的值都不同。

範例​

const id1: symbol = Symbol("id");
const id2: symbol = Symbol("id");

console.log(id1 === id2);

輸出：

false

使用情境​

建立唯一識別碼：

const USER_ID = Symbol("USER_ID");

大型框架底層常使用：

  • React
  • Vue
  • Node.js

typeof 檢查型別

JavaScript 提供：

typeof

來檢查資料型別。

String​

console.log(typeof "Hello");

結果：

string

Number​

console.log(typeof 100);

結果：

number

Boolean​

console.log(typeof true);

結果：

boolean

Null（特殊情況）​

console.log(typeof null);

結果：

object

這是 JavaScript 歷史遺留問題，不是 TypeScript 的 Bug。

Primitive Type vs Object Type

類型範例
Primitive Typestring、number、boolean
Object Typeobject、array、function

Primitive Type​

let name: string = "Tom";
let age: number = 18;

Object Type​

const user = {
  name: "Tom",
  age: 18,
};

常見錯誤

錯誤 1：數字使用字串​

let age: number = "18";

錯誤：

Type 'string' is not assignable to type 'number'

錯誤 2：布林值使用字串​

let isLogin: boolean = "true";

錯誤：

Type 'string' is not assignable to type 'boolean'

錯誤 3：忘記 BigInt 的 n​

let bigNumber: bigint = 100;

錯誤：

Type 'number' is not assignable to type 'bigint'

正確：

let bigNumber: bigint = 100n;

Primitive Type 總整理

Type範例
string"Hello"
number100
booleantrue
undefinedundefined
nullnull
bigint100n
symbolSymbol("id")

實務開發建議

最常用​

string;
number;
boolean;

約佔日常開發的 90% 以上。

API 資料​

通常搭配：

string | null;

或：

string | undefined;

BigInt​

主要用於：

  • 金融系統
  • 區塊鏈
  • 高精度計算

一般前端較少使用。

Symbol​

大多出現在：

  • 框架原始碼
  • 套件開發
  • 底層實作

一般業務開發較少使用。

本章重點

✅ Primitive Types 是 TypeScript 最基礎的型別

✅ 常見型別：

string;
number;
boolean;

✅ null 與 undefined 不同

null → 開發者主動設定
undefined → 尚未賦值

✅ bigint 用於超大整數

100n;

✅ symbol 用於建立唯一識別值

Symbol("id");
