> 在開始製作 React 專案前要先確定自己的電腦是否有安裝對應的套件了，如果沒有安裝，將會無法開始

## 環境確認

請先確認當前電腦是否安裝下面的套件

- Ndoe.js
- NPM

確認方式

1. 開啟終端機輸入`node -v`，如果顯示版本號，例如：`v18.16.1`，代表有安裝環境，如果沒有顯示請先去安裝 node.js
2. 終端機輸入`npm -v`，如果顯示版本號，例如：`10.9.2`，代表有安裝環境，如果沒有顯示請先去安裝 NPM
